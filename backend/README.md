# 🪞 Project Rumi — AI Core Backend (ZeroGPU + Gradio)

Project Rumi is an autonomous, empathetic AI life mirror that observes, understands context, and supports you in real time.

This Hugging Face Space serves as the central AI core backend, powered by **Gradio**, **FastAPI**, and Hugging Face **ZeroGPU** (`@spaces.GPU`).

## ⚡ Architecture

- **Platform**: Hugging Face Spaces (Free Gradio SDK + ZeroGPU)
- **Frontend Target**: Vercel (`https://*.vercel.app`)
- **Real-time Protocol**: WebSockets (`wss://<space-id>.hf.space/ws/observe`)
- **ZeroGPU Acceleration**: On-demand NVIDIA GPU allocation for vision analysis, tensor operations, and emotion recognition.
- **Multimodal AI**: Google Gemini 3.8 Live (Live API) / Gemini 3.5 Flash Lite (Vision, Canvas, Reasoning)
- **Memory & Identity**: Firebase Firestore with persistent contextual sessions.

## 🔌 Core Endpoints

| Type | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Gradio Control Panel & ZeroGPU Diagnostic Testbench |
| `GET` | `/health` | Core health & status check |
| `POST` | `/auth/verify` | Firebase token verification & identity lookup |
| `GET` | `/identity` | Current user identity attributes & preferences |
| `POST` | `/identity` | Update identity attributes |
| `GET` | `/session-summaries` | Retrieve past session summaries |
| `POST` | `/session/start` | Initialize a new observation session |
| `POST` | `/session/{id}/end` | End session and trigger auto-summarization |
| `POST` | `/session/{id}/resume`| Resume a paused session |
| `GET` | `/canvas/history` | Canvas entries generated by Rumi |
| `WS` | `/ws/observe` | Full duplex real-time video/audio observation pipeline |

## 🔑 Required Space Secrets

Set these under **Settings -> Variables and Secrets**:
- `GEMINI_API_KEY`: Google Gemini API key.
- `FIREBASE_SERVICE_ACCOUNT_JSON`: Firebase service account credentials (raw JSON or base64 string).
- `FIREBASE_STORAGE_BUCKET`: (Optional) Firebase Storage Bucket name.
- `FRONTEND_URL`: (Optional) Custom frontend URL (defaults allow all `*.vercel.app` and localhost).
